
Cross‑validation: Cross‑validation is a statistical method for assessing how a predictive model will perform on unseen data. It works by partitioning the available data into multiple subsets, training the model on some subsets and testing it on the remaining ones. The process is repeated so that each subset serves as a test set once, and the results are averaged to produce an overall performance estimate. This technique reduces the risk of overfitting and provides a more reliable measure of generalization than a single train‑test split. An expert in machine learning might apply k‑fold cross‑validation to compare several algorithms on a biomedical dataset, using the average validation accuracy to select the best hyper‑parameters and then reporting the mean and variance across folds as the final performance metric. Used in: A Study of Cross‑Validation and Bootstrap for Accuracy Estimation and Model Selection — the paper uses 10‑fold stratified cross‑validation to estimate classifier accuracy and to compare model selection methods.

Bias‑Variance Trade‑off: The bias‑variance trade‑off describes how prediction error can be split into three components: systematic error due to model assumptions, error due to sensitivity to training data fluctuations, and irreducible noise. Bias measures the error introduced by approximating a real‑world problem with a simplified model. Variance measures how much the model’s predictions change when trained on different data samples. The trade‑off states that reducing bias typically increases variance and vice versa, so optimal performance balances the two. An expert might compute bias and variance estimates for several candidate algorithms on a benchmark dataset, then select the model whose estimated total error is minimal to guide a research study on regularisation techniques. Used in: Neural Networks and the Bias/Variance Dilemma — the paper formally derives the bias‑variance decomposition and uses it to explain the generalisation behavior of neural networks.

Lasso: The Lasso is a regression method that adds an L1 penalty to the loss function. It minimizes the sum of squared residuals plus a tuning parameter times the sum of absolute coefficient values. The L1 penalty forces some coefficient estimates to be exactly zero, performing variable selection. By adjusting the tuning parameter, the method balances fit to the data with model sparsity. A genomics researcher fits a high‑dimensional linear model to gene expression data, selects the Lasso penalty via cross‑validation, and interprets the non‑zero coefficients as candidate biomarkers for a disease, thereby reducing the predictor set while maintaining predictive performance. Used in: Regression Shrinkage and Selection via the Lasso — introduces the Lasso estimator and demonstrates its ability to produce sparse models through L1 regularization.

Bootstrap Sampling: 1. Bootstrap sampling is a statistical method used to estimate the variability of a statistic by resampling with replacement from the original sample, it involves creating multiple new samples from the original data, and calculating the statistic of interest for each new sample, the resulting distribution of the statistic is an estimate of the sampling distribution, and it allows researchers to assess the variability of the estimate without having to collect new data.

Holt-Winters method: 1. The Holt-Winters method is a statistical technique used for forecasting future values in a time series, it is based on historical data and takes into account trends and seasonality, the method is an extension of exponential smoothing, and it is used to make predictions about future values. The Holt-Winters method uses a set of equations to update the forecast for each period, it is a popular method for forecasting data with strong seasonal components. The method is flexible and can be used for a wide range of data, it is also relatively simple to implement. The Holt-Winters method is a powerful tool for forecasting and is widely used in many fields.
